# curtainandsheer

แอปหน้าเดียวสำหรับตรวจม่านโปร่ง/ม่านทึบรายห้อง (Dooya / Smart curtain) — ใช้บนมือถือ ตรวจ 11 หัวข้อต่อห้อง
สรุปปัญหาแยกตามอาการ/ชั้น/แบรนด์ และ **ซิงก์ขึ้น Google Sheet แบบเรียลไทม์**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (เปิดตรง ๆ หรือวางบน GitHub Pages ได้เลย ไม่ต้อง build) |
| `apps-script/Code.gs` | สคริปต์ฝั่ง Google Sheet — รับ/ส่งข้อมูลให้แอป |
| `SETUP.md` | วิธีเชื่อมแอปกับชีต ทำครั้งเดียว |

## การซิงก์ทำงานยังไง

```
มือถือ/เบราว์เซอร์  ──POST บันทึกทีละห้อง──▶  Apps Script Web App  ──▶  Google Sheet
        ▲                                                                  │
        └────────────── GET ทุก 15 วินาที (+ ตอนสลับกลับมาที่แท็บ) ─────────┘
```

- กด **บันทึก** ครั้งเดียว ขึ้นชีตทันที ไม่ต้องคัดลอกวาง
- ชีตคือแหล่งข้อมูลกลาง หลายเครื่องตรวจพร้อมกันแล้วเห็นตรงกัน
- เน็ตหลุดก็ยังตรวจต่อได้ ข้อมูลเข้าคิวไว้ในเครื่อง แล้วส่งเองเมื่อกลับมาออนไลน์
- ยังเก็บสำเนาไว้ใน localStorage เสมอ และยังดาวน์โหลด CSV ได้เหมือนเดิม
