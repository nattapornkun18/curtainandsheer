# curtainandsheer

แอปหน้าเดียวสำหรับตรวจม่านโปร่ง/ม่านทึบรายห้อง (Dooya / Smart curtain) — ใช้บนมือถือ ตรวจ 11 หัวข้อต่อห้อง
สรุปปัญหาแยกตามอาการ/ชั้น/แบรนด์ และ **ซิงก์ขึ้น Google Sheet แบบเรียลไทม์**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (เปิดตรง ๆ หรือวางบน GitHub Pages ได้เลย ไม่ต้อง build) |
| `apps-script/Code.gs` | สคริปต์ฝั่ง Google Sheet — เขียนลงแท็บเดิม (`Check ม่าน`) ไม่สร้างแท็บใหม่ |
| `SETUP.md` | วิธีเชื่อมแอปกับชีต ทำครั้งเดียว |

## การซิงก์ทำงานยังไง

```
มือถือ/เบราว์เซอร์  ──POST บันทึกทีละห้อง──▶  Apps Script Web App  ──▶  Google Sheet
        ▲                                                                  │
        └────────────── GET ทุก 15 วินาที (+ ตอนสลับกลับมาที่แท็บ) ─────────┘
```

- กด **บันทึก** ครั้งเดียว ขึ้นชีตทันที ไม่ต้องคัดลอกวาง
- หนึ่งห้อง = หนึ่งแถวในแท็บเดิม ตรวจซ้ำทับแถวเดิมพร้อมอัปเดตวันที่ ไม่งอกแถวใหม่
- ไม่แตะคอลัมน์ที่แอปไม่รู้จัก (เช่น `สถานะ`) และไม่เขียนทับช่องที่เป็นสูตร
- ชีตคือแหล่งข้อมูลกลาง หลายเครื่องตรวจพร้อมกันแล้วเห็นตรงกัน
- เน็ตหลุดก็ยังตรวจต่อได้ ข้อมูลเข้าคิวไว้ในเครื่อง แล้วส่งเองเมื่อกลับมาออนไลน์
- ยังเก็บสำเนาไว้ใน localStorage เสมอ และยังดาวน์โหลด CSV ได้เหมือนเดิม
- ไม่มีปุ่มไหนในแอปที่ลบข้อมูลในชีตได้

## รูปถ่ายแนบ

ใต้ช่องหมายเหตุมีปุ่มถ่ายรูป แนบได้ 3 รูปต่อการบันทึก
รูปถูกย่อและบีบในมือถือก่อนส่ง (4 MB → ~200 KB) แล้วเก็บใน Google Drive
วางลิงก์ไว้ในคอลัมน์ `รูปถ่าย` ของชีต และแนบไปในข้อความ LINE ด้วย
บันทึกซ้ำโดยไม่แนบรูปใหม่ รูปเดิมไม่หาย · อัปรูปพลาดข้อมูลห้องยังลงชีตครบ

## แจ้งเตือนเข้า LINE

ใส่ `LINE_TOKEN` ใน `Code.gs` แล้วเวลามีคนกลับไป **แก้ไขห้องที่เคยบันทึกไว้แล้ว** จะมีข้อความเด้งเข้า LINE
บอกว่าห้องไหน เปลี่ยนจากอะไรเป็นอะไร ใครแก้ และตรวจครั้งก่อนเมื่อไหร่
ตรวจครั้งแรกไม่แจ้ง · บันทึกซ้ำโดยไม่เปลี่ยนอะไรก็ไม่แจ้ง · แก้หลายห้องยุบเป็นข้อความเดียว
ปรับเป็นแจ้งทุกครั้ง / เฉพาะห้องที่เสีย / ปิด ได้ที่ `NOTIFY_WHEN`
ส่งไม่สำเร็จก็ไม่กระทบการบันทึก ข้อมูลลงชีตครบเหมือนเดิม
(วิธีตั้ง LINE OA และเรื่องโควตาข้อความอยู่ใน [SETUP.md](SETUP.md#แจ้งเตือนเข้า-line))

## รหัสผ่าน

ตั้ง `TOKEN` ใน `Code.gs` ที่เดียว แอปจะขึ้นหน้าล็อกให้กรอกก่อนใช้งานเอง
รหัสเดียวกันนี้คือรหัสที่ Apps Script ใช้ตรวจทุก request — ไม่มีรหัสก็ **อ่านไม่ได้ เขียนไม่ได้**
ไม่ใช่แค่ซ่อนหน้าจอ (ดูรายละเอียดใน [SETUP.md](SETUP.md#รหัสผ่าน))
